# DRIFT

A third-person puzzle game about switching between a broken world and its restored form.

## Run

Open the project in Unity 6000.3.25f1, open `Assets/Scenes/MainMenu.unity`, and press Play.

## Controls

- WASD: move
- Mouse: look
- Space: jump
- Shift: sprint
- Q: switch reality after collecting the artifact
- E: interact
- Escape: pause

Normal World lasts 15 seconds. Falling returns you to your current checkpoint.

## Development

Use **DRIFT > Scenes** to edit the Cave or Broken World. Keep the three scene names unchanged; Play starts through MainMenu.

Use **DRIFT > Build Windows** to create a build in `Builds/Windows`. For gameplay checks, start a fresh Play session and select **DRIFT > Check Gameplay**.
